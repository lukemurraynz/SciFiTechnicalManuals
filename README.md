# SciFi Technical Manuals

**Unofficial, fan-made in-universe technical references for twenty-two science fiction universes.**

Prepared in the tradition of the classic *Star Trek* Writers'/DS9 Technical Manuals: each volume is written as if it were an internal document of its own universe, consolidating established canon with clearly marked engineering extrapolation.

## House Format

1. Edition pin: an exact in-universe moment the volume reflects.
2. Numbered parts: theater, central installation deep-dive, travel ops, vessels, weapons, threat dossiers, command structure, bestiary.
3. Honest markers: unmarked = canon; **[E]** = extrapolation; **[W]** = writer's latitude.
4. Threat dossiers end in engagement rules; every capability has a recorded cost.
